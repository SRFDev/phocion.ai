# phocion.ai

Minimal credibility page for [Phocion](https://phocion.ai), an AI data-security gateway. Not a product or marketing funnel — hero, problem statement, how-it-works, and honest status, nothing more.

Built with [Astro](https://astro.build), deployed on [Netlify](https://netlify.com).

## Development

```bash
npm install
npm run dev
```

Site runs at `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```
